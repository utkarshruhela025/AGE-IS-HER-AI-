# AGE-IS-HER-AI-
SOS Project is a Women’s Safety Application designed to enhance personal security by detecting emergency situations through high-decibel voice input and custom safety keywords. When a user shouts a predefined emergency word (such as "HELP", "SOS", or any custom keyword) at a high volume, the system automatically triggers safety actions like sending alerts, sharing location, and notifying emergency contacts.

🚀 Features

🎤 Voice Activation

Listens for predefined emergency keywords.
Supports custom trigger words set by the user.

🔊 High-Decibel Detection

Ensures activation only when the keyword is spoken loudly enough to indicate distress.
Reduces accidental triggers.

📍 Real-Time Location Sharing

Sends the user's live location to emergency contacts.

📩 Emergency Alerts

Automatically sends SMS, notifications, or emails to registered contacts.

🚨 Instant SOS Trigger

Activates emergency mode without requiring physical interaction.

🔒 Privacy & Security

Processes audio locally whenever possible.
Stores sensitive information securely.
🛠️ Technologies Used
Programming Language: Python / Java / Kotlin (depending on implementation)
Speech Recognition: Google Speech API / SpeechRecognizer
Audio Processing: PyAudio / Android AudioRecorder
Location Services: GPS API
Notification Service: SMS Gateway / Firebase
